# TherapyApp
Opinnäytetyöprojekti, jonka aiheena pelillistetty terapiasovellus. Sovellus on selainpohjainen, ja sen tarkoituksena on seurata käyttäjän ja terapeutin yhdessä sopimien tehtävien toteutumista.

## Tavoitteet
- käyttäjä voi luoda omia tehtäviä
- käyttäjä voi määrittää tehtävien toistuvuuden
- käyttäjä voi merkitä tehtäviä suoritetuksi
- käyttäjä voi seurata omaa edistymistään
- sovellus tarjoaa kannustavaa palautetta
- käyttöliittymä toimii eri laitteilla

## Teknologiat
- HTML
- CSS
- JavaScript
- PHP
- MariaDB (hallinta phpMyAdmin)

## Käyttöönotto
1. Kloonaa repository
2. Luo tietokanta
3. Luo tietokantarakenne SQL-tiedostoista
4. Määritä tietokantayhteys
5. Käynnistä sovellus paikallisessa ympäristössä

## Kehityksen tila
Projektin alustava kehitys on saatu loppuun ja opinnäytetyö valmiiksi. Projekti on valmiina jatkokehitykseen.

## Jatkokehityskohteita
- käyttäjähallinta
- tietoturvan vahvistaminen
- terapeuttinäkymän kehittäminen
- ilmoitus- ja muistutustoiminnot
