# TherapyApp
Opinnäytetyöprojekti, jonka aiheena pelillistetty terapiasovellus. Sovellus on selainpohjainen, ja sen tarkoituksena on seurata käyttäjän ja terapeutin yhdessä sopimien tehtävien toteutumista.

## Tavoitteet
- käyttäjä voi luoda omia tehtäviä
- käyttäjä voi määrittää tehtävien toistuvuuden
- käyttäjä voi merkitä tehtäviä suoritetuksi
- käyttäjä voi seurata omaa edistymistään
- sovellus tarjoaa kannustavaa palautetta
- käyttöliittymä toimii eri laitteilla
